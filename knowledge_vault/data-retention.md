# Data Retention

- For Data Retention, the record retention period is 70 days.
- For Data Retention, the escalation deadline is 66 minutes.
- For Data Retention, the required approvals is 46 approvers.
- For Data Retention, the review frequency is every 96 weeks.
- For Data Retention, the cooling-off period is 60 days.
- For Data Retention, the responsible owner is the Security Officer.
